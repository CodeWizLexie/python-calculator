# Python Calculator
A simple calculator in Python

## Quick Start
1. Enter which operator you want to use from the list: plus(+), minus(-), addition(*), power(**), modulo (%)
2. Enter your first number
3. Enter your second number
4. Upon being prompted whether you want to use the application again, enter "Y" for yes and "N" for no
